    Executors¶

    Executors start subprocesses for command wrappers. Pass an instance as executor= when constructing a Commands subclass, or bind them in maestro.yml (see Executors).

    maestro.executors.base.Executor ¶

    Executor()

    Bases: Protocol

    factory classmethod ¶

    factory(c, executor_id, _seen=None)

    Build an executor from config (default, aliases, or type + options).

    The maestro.yml should be of the format

    executors:
    vitis_env:
        type: docker
        image: vitis:2025.2
        ...
        binds:
            - [../cache, /cache, rw]
    hog_exe: vitis_env    # alias
    some_exe_id: default  # executor_id can be defined, but use default exe

commands:
    uv: some_exe_id       # assign an executor_id
    git: default          # directly use default
    vitis: vitis_env      #
    hog: hog_exe          # use alias executor_id
